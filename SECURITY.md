# Security Policy

Report suspected vulnerabilities privately to **info@agenticdome.io**.

Do not open a public GitHub issue for a vulnerability. Never include production API keys, tenant secrets, customer records, prompt content, tool arguments, or access tokens in a public issue or pull request.

Where safe, include the affected package version, a minimal synthetic reproduction, expected and observed behavior, sanitized logs, and a secure contact method. AgenticDome will acknowledge the report, assess impact, coordinate remediation, and discuss disclosure timing with the reporter.

Use the public [issue tracker](https://github.com/agenticdome/agenticdome-sdk-ts/issues) only for ordinary defects and feature requests without security impact.
